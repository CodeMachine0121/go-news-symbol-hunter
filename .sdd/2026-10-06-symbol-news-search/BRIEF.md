# 標的新聞搜尋 — Requirements Brief

## Goal
讓持有已啟用 API key 的使用者，只要提供標的與市場類別，就能取得該標的近期的新聞清單。系統依市場類別決定要向哪些新聞來源取新聞，合併、去重後依發布時間由新到舊回傳。這是之後 AI 分析標的時使用的「爬取新聞」能力，本切片先讓它可以被直接呼叫與驗證。

## Requirements
- 只有持有「已啟用且未撤銷」API key 的使用者可以搜尋新聞（沿用 API key 管理的把關規則）。
- 必須提供標的與市場類別；市場類別只接受加密貨幣、台股、美股三種。
- 標的去除前後空白；加密貨幣與美股標的不分大小寫，一律以大寫呈現。
- 依市場類別選擇新聞來源（由系統決定，使用者不能指定）：
  - 台股：鉅亨網、Google 新聞（繁體中文）。以公司簡稱搜尋（例如 2330 → 台積電）。
  - 美股：Yahoo 財經、Google 新聞（英文）。以標的代號搜尋。
  - 加密貨幣：CoinDesk、Cointelegraph、Google 新聞（英文）。以幣種名稱與代號比對（例如 BTC → Bitcoin）。
- 台股標的必須是證交所上市公司代號；加密貨幣標的必須是可辨識的幣種代號；辨識不到 → 告知找不到此標的。美股標的不另行驗證，查無新聞時回傳空清單。
- 只回傳最近 7 天內發布的新聞。
- 同一則新聞（標題相同）出現在多個新聞來源時只保留一則。
- 依發布時間由新到舊排序，最多回傳 30 則。
- 每則新聞包含：標題、連結、發布時間、新聞來源名稱，以及摘要（新聞來源有提供時）。
- 單一新聞來源失敗時，其餘新聞來源的結果照常回傳，並告知哪些新聞來源這次沒有取得資料。
- 所有新聞來源都失敗時，告知新聞來源暫時無法使用。

## Examples (Specification by Example)

### Rule: 只有已啟用的 API key 能搜尋
| # | Given | When | Then |
|---|---|---|---|
| 1 (happy) | 已啟用的 API key | 搜尋 BTC / 加密貨幣 | 回傳新聞清單 |
| 2 (exception) | 停用中的 API key | 搜尋 | 被拒，告知 API key 尚未啟用 |
| 3 (exception) | 未提供 API key | 搜尋 | 被拒，告知需要提供 API key |

### Rule: 市場類別與標的必須有效
| # | Given | When | Then |
|---|---|---|---|
| 1 (exception) | 市場類別「港股」 | 搜尋 | 被拒，告知市場類別只能是 crypto、twStock、usStock |
| 2 (exception) | 未提供市場類別 | 搜尋 | 被拒，告知市場類別只能是 crypto、twStock、usStock |
| 3 (exception) | 未提供標的（或只有空白） | 搜尋 | 被拒，告知標的為必填 |
| 4 (boundary) | 標的「 aapl 」/ 美股 | 搜尋 | 以 AAPL 搜尋，結果標的顯示 AAPL |
| 5 (exception) | 標的 9999 / 台股，證交所上市公司中沒有 9999 | 搜尋 | 被拒，告知找不到此標的 |
| 6 (exception) | 標的 NOTACOIN / 加密貨幣，辨識不到幣種 | 搜尋 | 被拒，告知找不到此標的 |
| 7 (boundary) | 標的 ZZZZ / 美股，新聞來源都沒有相關新聞 | 搜尋 | 成功，新聞清單為空 |

### Rule: 依市場類別選擇新聞來源與搜尋字
| # | Given | When | Then |
|---|---|---|---|
| 1 (happy) | 2330 / 台股，公司簡稱台積電 | 搜尋 | 向鉅亨網與 Google 新聞（繁中）以「台積電」搜尋 |
| 2 (happy) | AAPL / 美股 | 搜尋 | 向 Yahoo 財經與 Google 新聞（英文）以 AAPL 搜尋 |
| 3 (happy) | BTC / 加密貨幣，幣種名稱 Bitcoin | 搜尋 | 向 CoinDesk、Cointelegraph、Google 新聞（英文）取新聞；CoinDesk 與 Cointelegraph 只保留標題或摘要提到 Bitcoin 或 BTC 的新聞 |

### Rule: 時間範圍、去重、排序與數量
| # | Given | When | Then |
|---|---|---|---|
| 1 (boundary) | 一則新聞發布於 6 天 23 小時前，一則發布於 7 天 1 小時前 | 搜尋 | 只回傳前者 |
| 2 (happy) | 鉅亨網與 Google 新聞都有標題「台積電法說會」的新聞 | 搜尋 | 只出現一則 |
| 3 (happy) | 三則新聞分別發布於昨天、今天、前天 | 搜尋 | 順序為今天、昨天、前天 |
| 4 (boundary) | 符合條件的新聞有 45 則 | 搜尋 | 只回傳最新的 30 則 |

### Rule: 新聞來源失敗
| # | Given | When | Then |
|---|---|---|---|
| 1 (exception) | Google 新聞失敗，鉅亨網成功 | 搜尋台股 | 回傳鉅亨網的新聞，並告知 Google 新聞這次沒有取得資料 |
| 2 (exception) | 所有新聞來源都失敗 | 搜尋 | 被拒，告知新聞來源暫時無法使用 |
| 3 (exception) | 辨識標的所需的資料（上市公司清單或幣種清單）取不到 | 搜尋 | 被拒，告知新聞來源暫時無法使用 |

## Out of Scope
- AI 分析（下一個切片）。
- 新聞內文全文擷取；只用新聞來源提供的標題與摘要。
- 新聞落地保存、快取。
- 上櫃、興櫃股票。
- 使用者自訂時間範圍、數量或新聞來源。

## Open Decisions
- 新聞來源的連線逾時長度。
- 證交所上市公司清單與幣種清單是否需要快取（每次搜尋都要辨識標的）。

## Context / Background
- 新聞來源的免費使用條款可能變動；Google 新聞的使用條款限個人非商業用途，對外服務有法律風險，需在 PRD 風險記錄。
- 「同一則新聞」以標題比對（去除前後空白、不分大小寫），不同來源連結格式不同（Google 新聞為轉址連結），無法以連結比對。
